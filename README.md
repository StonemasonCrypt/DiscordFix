>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает файлы WinDivert потенциально опасными или относит их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, предпочтительно добавить исключение; если назначение параметра непонятно, рекомендуется отключить детектирование PUA.

## ⚙️Установка и запуск

1. Настройте безопасный DNS (Secure DNS):
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и укажите URL вручную. Например, `https://dns.google/dns-query` — Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в параметрах самой системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/StonemasonCrypt/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг можно не выполнять.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите подходящий файл:
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить автозапуск, выберите в **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) запускает выбранную стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты ALT, FAKE и другие, пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные действия:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск Windows (`services.msc`)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  После изменения параметра нужно перезапустить стратегию.  
  Текущее состояние — включено или выключено — показано в скобках.
  - **`IPSet Filter`** — переключение режима обхода ресурсов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который напрямую открывается, но перестаёт работать с zapret.  
  В скобках отображается режим:
    - `none` — ни один IP не проверяется
    - `loaded` — IP сверяется со списком
    - `any` — под фильтр попадает любой IP
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** — ручная проверка новых версий
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret не запускается или не работает.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной потере работоспособности.
  - **`Run Tests`** — проверка стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть в панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/StonemasonCrypt/zapret-discord-youtube/issues/522).

### Рабочей стратегии нет

- Откройте командную строку от имени администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не подключается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - В появившейся папке откройте `hosts` текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа этого способа не гарантируется. Если он не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/StonemasonCrypt/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Стратегия способна работать некоторое время, а затем перестать работать после обнаружения.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` → `Run Diagnostics` и убедитесь, что там нет ошибок.
- Проверьте, внесён ли адрес нужного ресурса в списки доменов или IP.
- Испытайте другие стратегии, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/StonemasonCrypt/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` → `Remove Services`.
- Затем откройте `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце выберите `Y`.
- Удалите старый каталог zapret.
- Загрузите последнюю версию со [страницы релизов](https://github.com/StonemasonCrypt/zapret-discord-youtube/releases), архив вида `zapret-discord-youtube-...`.
- Нажмите правой кнопкой мыши по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска, не используя пробелы, специальные символы и кириллицу.
- Поочерёдно запустите разные скрипты `general`. Проверяйте интернет-ресурсы; если они не открываются, завершите программу через значок замка в панели задач и попробуйте следующую стратегию.
- После нахождения рабочего варианта включите автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Определите имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Перезапустите проверку с другими стратегиями, особенно если раньше всё работало.
- См. также [#251](https://github.com/StonemasonCrypt/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительное обсуждение: [#252](https://github.com/StonemasonCrypt/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/StonemasonCrypt/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:
- в `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: при `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/StonemasonCrypt/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/StonemasonCrypt/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
